# Reference canvas

Source of the frame-by-frame reference build of pages 01 and 02, published at
https://claude.ai/artifact/BY1KTiAR8iatQQZirH1C8z

One `.dc.html` per artboard, `canvas.json` for page assignment and layout.
Each file is plain HTML with inline styles: open it in a browser for a rough
look (the `support.js` include is only present on the hosted canvas and can be
ignored), or read it for the exact copy, sizes, colors and SVG coordinates
when rebuilding the frames in Paper.
